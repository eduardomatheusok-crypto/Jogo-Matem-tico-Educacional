# Jogo-Matematico-Educacional

Math Rush

Math Rush é uma plataforma educativa gamificada desenvolvida com HTML, CSS e JavaScript puro, criada para tornar o aprendizado matemático mais interativo e dinâmico.

O sistema permite que professores criem quizzes personalizados por níveis de dificuldade, enquanto os alunos respondem às perguntas em uma interface moderna com pontuação, vidas, cronômetro e progressão de fases.

Funcionalidades:
Cadastro personalizado de perguntas
Sistema de múltipla escolha
4 níveis de dificuldade
Sistema de pontuação
Controle de vidas
Cronômetro
Progressão de perguntas
Feedback visual de acertos e erros
Ranking local utilizando LocalStorage
Interface responsiva e moderna

Níveis:

Level 1 — Operações Básicas
Adição
Subtração
Multiplicação
Divisão

Level 2 — Frações
Fração própria
Fração imprópria
Fração equivalente
Fração aparente
Números mistos

Level 3 — Expressões Numéricas
Ordem das operações
Parênteses
Multiplicação e divisão

Level 4 — Potenciação
Base e expoente
Quadrado e cubo
Operações com potência

Tecnologias Utilizadas:
HTML5
CSS3
JavaScript
LocalStorage

Objetivo do Projeto:

O objetivo do projeto é oferecer uma experiência simples e intuitiva de aprendizagem matemática através da gamificação, simulando um ambiente onde professores podem criar atividades e alunos podem responder de forma interativa.
